# ZEON App

ZEON App is a cross-platform proxy client developed and maintained by the ZEON team. We build our own product, releases, integrations, support flow, and user experience, while using ZEON as one of the technical foundations for the ZEON project.

The app is designed for simple profile management, broad protocol support, and convenient access on desktop and mobile platforms.

## Main Features

- Cross-platform client for Android, iOS, Windows, macOS, and Linux.
- Simple profile import and subscription management.
- Automatic subscription updates.
- Delay-based node selection.
- TUN mode and remote profiles.
- Support for VLESS, VMess, Reality, TUIC, Hysteria, WireGuard, SSH, and other protocols.
- Support for Sing-box, V2Ray, Clash, and Clash Meta configuration formats.
- Profile information with remaining days and traffic usage.
- Dark and light themes.
- Compatibility with common proxy management panels.

## Development

ZEON App is maintained by our own development team. The project includes Flutter application code and native/core components used for network configuration, routing, and platform integration.

If you work with the codebase, start with the existing project structure and tooling. Translation files are located in `assets/translations`.
