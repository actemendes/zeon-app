# ZEON App

ZEON App 是由 ZEON 团队开发和维护的跨平台代理客户端。我们负责自己的产品、版本发布、集成、支持流程和用户体验，同时将 Hiddify 作为 ZEON 项目的技术基础之一。

该应用面向移动端和桌面端，适合管理代理配置、订阅和多种协议。

## 主要功能

- 支持 Android、iOS、Windows、macOS 和 Linux。
- 便捷导入配置文件和管理订阅。
- 自动更新订阅。
- 根据延迟选择节点。
- TUN 模式和远程配置文件。
- 支持 VLESS、VMess、Reality、TUIC、Hysteria、WireGuard、SSH 等协议。
- 支持 Sing-box、V2Ray、Clash、Clash Meta 配置格式。
- 显示配置文件信息，包括剩余天数和流量使用情况。
- 深色和浅色主题。
- 兼容常见代理管理面板。

## 开发

ZEON App 由我们的开发团队维护。项目包含 Flutter 应用代码，以及用于网络配置、路由和平台集成的原生/core 组件。

如果你需要处理代码，请优先参考现有项目结构和工具。翻译文件位于 `assets/translations`。
