# ZEON App

ZEON App - кроссплатформенный прокси-клиент, который разрабатывает и поддерживает команда ZEON. Мы развиваем собственный продукт, релизы, интеграции, поддержку и пользовательский опыт, а ZEON взяли как одну из технических основ для проекта ZEON.

Приложение рассчитано на удобную работу с серверами ZEON, разными протоколами и платформами и обновляется под нужды RU сообщества.

## Основные возможности

- Кроссплатформенная работа: Android, iOS, Windows, macOS и Linux.
- Автоматическое обновление подписок.
- Выбор узла по задержке.
- TUN-режим и прокси.
- Поддержка VLESS, VMess, Reality, TUIC, Hysteria, WireGuard, SSH и других протоколов.
- Поддержка форматов Sing-box, V2Ray, Clash и Clash Meta.
- Отображение информации профиля: оставшиеся дни, трафик и другие данные.
- Темная и светлая темы.

## Разработка

ZEON App поддерживается нашей собственной командой разработчиков. В проекте есть Flutter-приложение, а также нативные и core-компоненты для сетевой конфигурации, маршрутизации и интеграции с платформами.

Если вы работаете с кодом, ориентируйтесь на текущую структуру проекта и существующие инструменты. Файлы переводов находятся в `assets/translations`.
