# Задача: новый интерфейс ZEON для Wear OS

Ты работаешь в репозитории `zeon-app` (Flutter, ветка от `codex/watch-ai-backup`). Нужно заменить
текущий временный экран часов `lib/features/watch/watch_proxy_page.dart` новым интерфейсом по
утверждённому макету и привязать к нему **существующий** функционал приложения. Новую бизнес-логику
не придумывай: каждый элемент UI вызывает уже имеющиеся провайдеры и сервисы. Закончить — значит
собрать APK, установить на часы и пройти приёмку ниже на реальном устройстве.

## 0. Перед началом (обязательно)

1. Прочитай `AGENTS.md` репозитория, `docs/README.md`, `docs/testing/README.md`.
2. Knowledge Base через `ssh zeon-server`: `/opt/zeon-knowledge/AI-AGENT-GUIDE.md`, страницу
   `02-PROJECTS/zeon-app/` (Architecture, VPN Core and Lifecycle, Control Plane Identity and
   Subscriptions), `09-DESIGN-SYSTEM/App-v3/App-v3-Components.md` (ConnectDial и таблица
   «состояние не определяется анимацией»). Найди в KB страницы про Wear/часы (`grep -ril "wear\|часы"`).
3. TickTick `💤ZEON`, область `zeon-app`: найди или создай одну задачу на эту работу.
4. Проверь Git: branch, HEAD, staged/unstaged/untracked. Чужую работу не трогай. Последние коммиты
   `fix(wear)/feat(wear)` (backup bridge, rootless proxy, Auto proxy backup) — рабочая основа,
   их поведение должно сохраниться.

## 1. Источник истины по дизайну

`docs/design/wear-vpn-v1/canvas/` — исходники утверждённого макета (HTML-компоненты Design canvas):

- `Vpn.dc.html` — экран часов целиком: разметка + класс `Component` с точной геометрией, цветами,
  таймингами, деревом навигации (`parents`), настройками (`choices`, `defaults`) и жестами. Это
  **спецификация поведения**: читай её код, а не только картинки.
- `VpnItem.dc.html` — карточка списка (title, group, profile, action, nav, toggle, choice, info,
  qr, note, status) и disabled-состояние.
- `Main.dc.html` — прототип потока: что делает каждое нажатие (connect, островок, привязка,
  оплата и автопроверка, обновление подписки, «Стартуем»). Таймеры там — имитация сервера.
- Остальные `*.dc.html` — статичные экраны-состояния; `canvas.json` — их названия.

Открыть визуально можно через владельца (холст «ZEON VPN Watch» в claude.ai); код в папке полный.

## 2. Что построить (кратко; детали — в `Vpn.dc.html`)

Палитра AMOLED: фон `#000`, поверхности `#1A1B1F`, текст `#F2F4F6`/`#B1B8C2`, акцент
`#3CE74F→#BFDD71`. Шрифт Montserrat (уже в assets). Круглые 480×480 и квадратные (inscribed);
форму экрана брать из платформы (`Configuration.isScreenRound`), не из размеров.

1. **Splash** — длинный логотип ZEON (Z E [градиентное кольцо] N), 1.5 с. Пути Z/E/N:
   `zeon-watch/wear/src/main/res/drawable/ic_wordmark.xml` (соседний репозиторий) + кольцо
   cx 215, cy 45.6, r 37.35, stroke 16.3. Старые `assets/images/SVG/logo-*`, `btn-*` — не использовать.
2. **Первый запуск** (вместо текущего redirect `/intro → /home` для часов):
   «СВОБОДНО. БЫСТРО. БЕСПЛАТНО», кнопка «СТАРТУЕМ / и премиум в подарок», «Я уже имею аккаунт».
   → «Привязка часов» (инструкция) → «Номер подписки»: 6 ячеек + клавиатура 3×4
   (очистить, 0, стереть), шестая цифра отправляет.
3. **Главный экран — кнопка на весь экран.** Тап в любом месте = `handleMainVpnButtonTap`.
   Анимация ConnectDial перенесена на край экрана: off — серая кайма; loading — дуга 216°
   (1.2π) с круглыми концами, оборот 1.5 с; connected — дуга замыкается в кольцо, градиент
   вращается 6 с; failed = off. Морф 460 мс easeInOutCubic, логотип Z (короткий знак) по центру,
   прозрачность .45/.7/1, нажатие — scale .96 за 140 мс. Внизу капсула текущего сервера.
   Часов и постоянного статуса на экране нет.
4. **Островок** — появляется только на событие (верх экрана, одна строка ≤ ~20 символов, 2–3 с),
   тап ведёт: подключение/сервер → выбор сервера; «Сбой подключения» → повтор; подписка → оплата.
5. **Пейджер** кнопка ↔ меню: один свайп вверх/вниз или шаг безеля/колеса; меню наверху —
   обратно к кнопке. Индикатор страниц справа.
6. **Меню**: карточка профиля (имя, «N дней · до D мес», полоса), «Оплатить», «Обновить подписку»,
   «Сервер», «Настройки», «Сменить аккаунт».
7. **Списки** (серверы, настройки, выбор значений) с эффектом линзы:
   `scale = 1.16 − 0.48·t²`, `opacity = 1 − 0.6·t²`, `t = min(1, |центр карточки − центр экрана| / (0.48·H))`.
8. **Оплата с телефона** — QR, две строки инструкции, статус «Ждём оплату… / Проверка через N с /
   Проверяю оплату… / Подписка обновлена / Проверка остановлена».
9. **Настройки** — дерево из `Vpn.dc.html` (`choices`, `lists.settings/sGeneral/sRouting/sTls/
   sSystem/sAbout`): то же, что в `settings_page.dart` и разделах, минус недоступное в режиме
   прокси (TUN, per-app, тема, вид кнопки, способ подключения — показан как «Прокси»).

Жесты Wear OS: свайп вправо — назад (системный swipe-to-dismiss/back, не своя кнопка);
безель/колёсико — прокрутка и пейджер (проверь, что rotary доходит до Flutter как scroll);
долгое нажатие на кнопку — выбор сервера; аппаратные «Назад»/«Домой» работают штатно.

## 4. Не выдумывать — выяснить и записать

- Макет говорит «6 цифр», а `isValidAccountNumber` принимает 1–16 цифр. Проверь по KB/Control Plane,
  какой формат реально у номера в `/open/…`; если не 6 — сделай число ячеек по факту и отметь.
- QR в макете ведёт на общий `zeonvpn.com/manager`; в приложении — персональная ссылка профиля.
  Использовать персональную.
- Что на часах делает «Стартуем», если embedded bootstrap недоступен (нет сети) — показать ошибку
  островком, не зависать.
- «Слабое устройство» и системный reduced motion: без анимаций края и линзы (как в App-v3).
- Экран часов гаснет: 10-минутная проверка оплаты прерывается — зафиксируй поведение, не обходи
  ограничения ОС молча.

## 5. Ограничения

- Режим на часах только прокси; не включать TUN/VPN. Не ломать backup bridge и Auto proxy backup.
- Секреты, токены, `google-services` и ключи не печатать и не коммитить; ничего не встраивать в APK.
- Сохранять данные приложения и debug signing identity при переустановке
  (см. `scripts/README.md` — раздел о сохранении установленной debug signing identity).
- ADB только с явным `-s <serial>`; перед `install`/`input` проверь модель и serial часов
  (Samsung Galaxy Watch, SM-L335F; serial — из KB/Runbooks). Другие устройства не трогать.
- Один законченный шаг — один осмысленный коммит. Не пушить без запроса владельца.

## 6. Приёмка на реальных часах (evidence в Temp, без секретов)

1. Чистый первый запуск: splash → «Стартуем» → профиль создан → главный экран.
2. Повтор с «Я уже имею аккаунт»: верный номер привязывает; неверный — ошибка островком, ячейки
   очищены.
3. Тап по экрану: off → loading (дуга бежит) → connected (кольцо); трафик через прокси
   `127.0.0.1:<port>` реально идёт (проверка из приложения с поддержкой прокси или adb-проверка);
   тап → off. Анимация не опережает реальное состояние.
4. Сбой (нет сети/сервер недоступен): вид off + островок «Сбой подключения», тап по нему — повтор.
5. Островок «Подключено»/сервер → тап открывает выбор сервера; выбор сервера при включённом
   соединении переподключает.
6. Безель и свайп: кнопка ↔ меню одним шагом; списки прокручиваются, линза работает;
   свайп вправо возвращает на уровень выше везде; долгое нажатие открывает серверы.
7. Оплата: QR сканируется телефоном и открывает персональный кабинет; после продления часы
   сами показывают «Подписка обновлена» и переподключаются; «Обновить подписку» в меню работает.
8. Каждая настройка меняет соответствующий `ConfigOptions`/`Preferences` и переживает перезапуск;
   порт меняет адрес прокси; фрагментация выключена → пункты неактивны (.42).
9. Круглые часы — основная проверка; квадратная раскладка — хотя бы эмулятор Wear OS square.
10. Регрессии: watch backup bridge и выключение/включение прокси после перезапуска часов.

В отчёте: SHA, что проверено на устройстве, что на эмуляторе, что не проверено и почему,
открытые вопросы из раздела 4. Обнови canonical-страницу KB и статус TickTick по AI-AGENT-GUIDE.
