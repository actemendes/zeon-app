## Как читать

Открывать только по конкретному root cause, версии или commit. Ветки, SDK,
идентификаторы тестовых устройств и команды относятся к периоду отчёта.
Часть старых evidence/исходников отсутствует в текущем checkout: такая ссылка
не доказывает PASS, но её исходная цель сохранена для поиска по истории.

Имена файлов сохранены, чтобы их было легко найти из старых TickTick/KB-ссылок.
Ранее перечисленные файлы лежали прямо в `docs/`; Apple TODO — в
`docs/apple-mac-ios-release/TODO.md`. JSON baseline manifests и HISTORY.md
не переписываются: они описывают старые деревья Git.
