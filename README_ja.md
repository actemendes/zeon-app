# ZEON App

ZEON App は、ZEON チームが開発および保守しているクロスプラットフォームのプロキシクライアントです。私たちは独自の製品、リリース、統合、サポート、ユーザー体験を開発し、ZEON を ZEON プロジェクトの技術的な基盤の一つとして利用しています。

このアプリは、デスクトップとモバイル環境でプロファイル、サブスクリプション、複数のプロトコルを扱いやすくするために作られています。

## 主な機能

- Android、iOS、Windows、macOS、Linux に対応。
- プロファイルのインポートとサブスクリプション管理。
- サブスクリプションの自動更新。
- 遅延に基づくノード選択。
- TUN モードとリモートプロファイル。
- VLESS、VMess、Reality、TUIC、Hysteria、WireGuard、SSH などのプロトコルに対応。
- Sing-box、V2Ray、Clash、Clash Meta の設定形式に対応。
- 残り日数や通信量などのプロファイル情報を表示。
- ダークテーマとライトテーマ。
- 一般的なプロキシ管理パネルとの互換性。

## 開発

ZEON App は私たちの開発チームが保守しています。プロジェクトには Flutter アプリケーションのコードと、ネットワーク設定、ルーティング、プラットフォーム統合のための native/core コンポーネントが含まれています。

翻訳ファイルは `assets/translations` にあります。
